# Data Dictionary

This document details the data structures, schemas, and metadata attributes maintained across the BMW Service Knowledge RAG application.

---

## 1. Document Schema
Represents raw uploaded or sample service files before chunking.

| Attribute Field | Data Type | Description | Example / Constraints |
| :--- | :--- | :--- | :--- |
| `document_id` | String (UUID) | Unique identifier for the raw document | `doc_8f9a2b1c` |
| `filename` | String | Original filename of the uploaded or sample file | `sample_ev_battery_service.txt` |
| `document_type` | String | Format extension | `PDF`, `TXT`, `DOCX`, `CSV` |
| `upload_timestamp` | String (ISO 8601) | Timestamp of document upload or ingestion | `2025-09-18T10:00:00Z` |
| `file_size_bytes` | Integer | Total size of the file in bytes | `1048576` |

---

## 2. Chunk Schema
Represents individual text segments generated after text cleaning and recursive splitting.

| Attribute Field | Data Type | Description | Example / Constraints |
| :--- | :--- | :--- | :--- |
| `chunk_id` | String | Unique identifier combining source, page, and chunk index | `sample_ev_battery_service.txt_p1_c0_a1b2c3` |
| `source` | String | Source document filename | `sample_ev_battery_service.txt` |
| `page` | Integer | Page number (1-indexed) where chunk originates | `1` |
| `document_type` | String | Format extension | `TXT` |
| `page_content` | String | Cleaned text content (~800 characters) | `"Check high-voltage battery cooling circuit..."` |
| `embedding` | Vector Float[384] | Dense vector representation generated by MiniLM-L6-v2 | `[0.012, -0.045, ...]` |

---

## 3. Query Schema
Represents technician search interactions and RAG generation results.

| Attribute Field | Data Type | Description | Example / Constraints |
| :--- | :--- | :--- | :--- |
| `query_id` | String (UUID) | Unique query session ID | `qry_4d5e6f7a` |
| `question` | String | Technician prompt / diagnostic question | `"What should be checked when an EV reports battery overheating?"` |
| `retrieved_chunks` | List[Chunk] | List of top-K chunks passing similarity threshold | List of top 4 chunks |
| `answer` | String | Final grounded text answer generated by Ollama LLM | `"Check coolant pump V54 and DTC 21A004..."` |
| `sources` | List[SourceMetadata] | Citations including document name, page, score | `[{"document": "...", "page": 1, "score": 0.85}]` |

---

## 4. Source Metadata Schema
Sub-structure for source attribution returned in API responses.

| Attribute Field | Data Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `document` | String | Name of cited document | `sample_ev_battery_service.txt` |
| `page` | Integer | Cited page number | `1` |
| `document_type` | String | Cited document format | `TXT` |
| `score` | Float | Normalized similarity score [0.0 - 1.0] | `0.8524` |
| `chunk_id` | String | Target chunk identifier | `sample_ev_battery_service.txt_p1_c0_a1b2c3` |
